# MEasyMate Logo Standard V1

**Document Type:** Brand Standard  
**Version:** V1  
**Status:** ACTIVE BASELINE  
**Brand:** MEasyMate = Make Everything Easy

## 1. Brand Principle

MEasyMate ต้องดู **ทันสมัย เป็นมิตร ฉลาด ใช้ง่าย และเชื่อมโยงกับ AI/Digital Tools**

ภาพหลักของแบรนด์ใช้แนวทางจากโลโก้และ Banner ที่อนุมัติ:
- Wordmark: **MEasyMate**
- Tagline: **Make Everything Easy.**
- Mascot: Friendly AI Mate / Robot
- Mood: Friendly + Smart + Modern + Trustworthy

## 2. Logo System

### A. Master Brand Logo
ใช้ในหน้า MEasyMate หลัก, Website Hub, LINE, Banner, เอกสารแบรนด์

องค์ประกอบ:
- MEasyMate wordmark
- Tagline `Make Everything Easy.`
- สามารถมี AI Mate mascot
- ใช้ Blue / Cyan / Teal-Green เป็นตระกูลสีหลัก

### B. Compact Logo / App Icon
ใช้เมื่อพื้นที่เล็ก:
- favicon
- shortcut icon
- app icon
- profile image
- mobile header

รูปแบบที่อนุญาต:
- `M` symbol
- `M + mascot`
- mascot face + M identity

ต้องอ่านออกชัดเมื่อย่อขนาด

### C. Project Logo / Sub-brand
Project สามารถมี Logo เฉพาะได้เมื่อมีเหตุผลด้าน Product Identity

รูปแบบแนะนำ:
- `MEasyMate Money`
- `MEasyMate Report Pro`
- `MEasyMate Contact Shift`
- หรือ `AIsure — by MEasyMate`

Project Logo ต้องคงอย่างน้อย 2 สิ่งจาก Brand Family:
1. สี / visual language ของ MEasyMate
2. MEasyMate endorsement เช่น wordmark, M symbol หรือ `by MEasyMate`

## 3. Core Color Direction

สีอ้างอิงจาก Visual Direction ปัจจุบัน:

- Deep Navy: `#0C1E31`
- MEasyMate Blue: `#299AC7`
- Light Cyan: `#78D1DA`
- Teal / Green accent: ใช้ในตระกูล cyan-teal ที่เข้ากับ Master Logo
- White: `#FFFFFF`

Project สามารถมี Accent Color เพิ่มได้ แต่ห้ามทำให้สูญเสียภาพจำ Blue/Cyan/Teal ของแบรนด์แม่

## 4. Typography Direction

- ใช้ Sans-serif ที่อ่านง่ายบนมือถือ
- หัวข้อ: Modern / Friendly / Clear
- เนื้อหา: อ่านง่าย ไม่บางเกินไป
- ชื่อ `MEasyMate` ต้องสะกดแบบนี้เป็นมาตรฐาน
- Tagline มาตรฐาน: `Make Everything Easy.`

## 5. Mascot Rule

AI Mate mascot เป็นตัวแทน “เพื่อน AI” ของแบรนด์

ใช้ได้ใน:
- onboarding
- help
- promotion
- banner
- assistant/AI features

ไม่จำเป็นต้องใส่ mascot ทุกหน้าจอ และไม่ควรใช้จนรบกวนการใช้งาน

## 6. Clear Space & Readability

- ห้ามวาง Logo ชิดขอบจนดูอึดอัด
- ห้ามย่อจนอ่าน `MEasyMate` ไม่ออก
- พื้นหลังต้องมี contrast เพียงพอ
- ถ้าพื้นหลังซับซ้อน ให้ใช้พื้นที่ขาว/โปร่งรอง Logo

## 7. Do Not

ห้าม:
- เปลี่ยนชื่อสะกดของ MEasyMate
- บีบ/ยืด Logo ผิดสัดส่วน
- เปลี่ยนสีหลักจนไม่เหลือ Brand Family
- ใช้หลายโลโก้แข่งกันในหน้าเดียว
- สร้าง Project Logo ที่ดูเหมือนคนละบริษัทโดยไม่มี `MEasyMate` endorsement

## 8. Project Design Gate

ก่อนสร้าง Logo ใหม่ของ Project ต้องตอบ:
- จำเป็นต้องมี Project Logo แยกจริงหรือไม่?
- ใช้ Master Logo ได้หรือไม่?
- ถ้าแยก จะเชื่อมกลับ MEasyMate อย่างไร?
- Icon ขนาดเล็กยังอ่านได้หรือไม่?

ค่าเริ่มต้นคือ **ใช้ Master Brand ก่อน** แล้วค่อยสร้าง Project Logo เมื่อมีเหตุผล

## 9. Standard Declaration

ใช้ข้อความสั้นใน Project:

`This project follows MEasyMate Logo Standard V1.`

## Final Rule
